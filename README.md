# Sport.com — projet Boxe

Site vitrine de la boutique fictive Sport.com, réalisé en BTS SIO SLAM (Aurlom).

## L'équipe

- **Corey LAURENT** — création du dépôt, en-tête et pied de page, page catalogue (bannière et produits), page Qui sommes-nous (histoire, chiffres clés, équipe, magasin, carte OpenStreetMap, formulaire de contact), responsive sous 576 px, corrections W3C, relecture des pull requests.
- **Medi-Ryan Mamona** — améliorations du site : défilement doux, lien de la page actuelle en orange, effet de survol des produits, contour visible au clavier, icône d'onglet.

## Le site en ligne

https://coreylaurent.github.io/sportcom-boxe/

## Les pages

- `index.html` : le catalogue
- `qui-sommes-nous.html` : la boutique, l'équipe, le magasin (carte) et le formulaire de contact

## Organisation du travail

Une branche par fonctionnalité, fusionnée dans `main` par une pull request :

| Branche           | Contenu                                 |
| ----------------- | --------------------------------------- |
| entete-pied       | En-tête et pied de page communs         |
| catalogue         | Bannière et quatre produits             |
| qui-sommes-nous   | Titre, histoire, chiffres clés, équipe  |
| magasin-contact   | Adresse, horaires, carte, formulaire    |
| responsive        | Media query sous 576 px, tests à 375 px |
| readme            | Ce fichier                              |
| amelioration-site | Améliorations (Prénom NOM)              |

Chaque pull request a été relue avant d'être fusionnée dans `main`.
